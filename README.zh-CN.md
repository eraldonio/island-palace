# 岛屿宫殿 Island Palace

[English](README.md) | **简体中文**

> 一个跑在浏览器里的独立 3D 记忆宫殿搭建器：先盖一栋房子，再长成一座海岛小镇，一直拉远到群岛——再远一点，整个世界会卷成一颗小星球。

岛屿宫殿是 [思维宫殿 KMind Palace](https://github.com/suka233/kmind-palace)（作者 suka）的 fork。这个 fork 只保留 3D 搭建的部分，其余全部去掉：不记笔记、不复习、没有闪卡、没有 AI 记忆故事、没有数字编码、没有串门、没有新手引导。留下来的就是一个用来搭东西的地方：宫殿、家具、房间、一整个世界，还有一只住在里面的小管家。

## 能做什么

- 🏝 **搭一个世界**：岛上小镇 → 群岛 → 小星球；海岛、森林、雪山、浮空岛四种场景，还能切换白天 / 夜晚。
- 🏗 **搭建模式**：加房间、砌墙、开门窗；从目录里添家具，移动、旋转、细调每一件（尺寸、颜色、挂墙位置）。
- 📝 **便签**：把便签平铺在岛上；可以就地直接写，也可以打开富文本编辑器写；纸色和预览字号都在它自己的菜单里。
- 📦 **自己的模型和照片**：可以导入 `.glb` 模型，也可以用自己的照片做贴图。
- 🦉 **小管家**：五种动物，配色和配饰随便换，住在你的岛上跟着你走。
- 🔒 **数据都在你自己的浏览器里**：宫殿、世界和照片都存在本地；没有账号、不连服务器、没有统计。
- 🌍 **简体中文和英文**：界面跟随浏览器语言。

## 运行

需要 Node.js 22+ 和 pnpm。

```bash
pnpm install
pnpm dev                      # 浏览器里的应用：http://127.0.0.1:5181（?lang=en 看英文界面）
pnpm typecheck && pnpm test   # 类型检查 + 单元测试
```

## 目录结构

```
packages/
  core/   整个应用：宫殿的数据格式、three.js 场景、界面与交互
docs/
  sticky-note.md   便签世界元素的规格（已实现）
AGENTS.md          给后续开发者 / 智能体的工作笔记：命令、坑、怎么验界面
```

**多语言**：界面文字写成 `t('中文原文')`，英文字典在 `packages/core/src/i18n/en/`；`pnpm -C packages/core i18n` 会列出还没翻译的地方，测试也会拦住漏翻。

## 联网说明

岛屿宫殿不连任何服务器：没有统计、没有分析、不调用任何接口。宫殿和照片都不会离开你的浏览器。
