# 便签 — 世界元素规格

[English](sticky-note.md) | **简体中文**

> 状态：**已实现**（先写规格，再照着搭出来）。取舍见 §10。

## 1. 概述

便签是一种可以**加入世界**的新元素。它**平铺在地面上**，直接把内容显示在场景里，并且可以有**两种编辑方式**：直接在地面上改，或者打开后用**完整的所见即所得编辑器**改。

## 2. 元素与数据

- 区域上的**一等公民**元素：`palaces`、`props` 之外新增一个 `region.notes` 数组。
- 存档格式：抬高 `WORLD_VERSION`（4 → **5**），`WORLD_COMPAT` 保持 `1`——旧存档仍能读。
- 一张便签：

  | 字段 | 含义 |
  | --- | --- |
  | `id` | 生成（`gid('note-')`），和 props 一样 |
  | `pos` | 区域平面上的 `[x, z]`，米 |
  | `rot` | 绕 y 轴的角度，度 |
  | `w`、`h` | 基础尺寸，米 |
  | `color` | `NOTE_COLORS` 里的序号 |
  | `fs` | 预览文字高度，米 |
  | `html` | 内容，清洗过的 HTML 子集（§6） |

## 3. 摆放

- **添加方式**：搭建界面里的一个**便签工具**；**点地面**就在那里放一张。
- **吸附**：和其他所有摆放物件完全一致——吸附到 **5 cm 网格**（`GRID = .05`），受现有**吸附开关**
  控制，**Alt** 临时关闭。
- **旋转**：开着吸附时按 **15°** 步进（`ANGLE = 15`），Alt 时自由旋转；按 **`R`** 转 90°。
- 便签**不参与碰撞**：它是平的、不阻挡，所以不做宫殿地块或摆设的避让。

## 4. 外观

- **基础尺寸**：默认 **2.0 m × 1.5 m**；**调整尺寸**允许 **1.0 – 40.0 m**（和最大的一座岛差不多大）。
  卡片上放大 / 缩小的一档跟着当前尺寸走（≥ 0.5 m，落在 0.5 m 的整数倍上），所以整个范围几下就点到了；
  细调用四角的句柄。
- **四角的句柄与选中框**：选中便签后，贴合纸面的橙色选中框（`kp-note-frame`）与四个角上的缩放句柄
  同时出现，与便签共享同一个仿射矩阵。拖动句柄可以**独立改宽和深**（不必成比例），吸附到 5 cm 网格
  （**Alt** 自由），并且以**对角那个角为轴**——对角保持不动。选中框与句柄均置于 `z-index: 1`，压在三维
  画布之上、但低于卡片（2）、面板（3）及全屏弹层（8），不会浮在弹层上方。投影前强制刷新相机矩阵，
  消除镜头旋转阻尼时 DOM 句柄相对便签延迟漂移的问题。
- **背景色**：6 种浅色纸色，导出为 `NOTE_COLORS`；颜色名走 `t()`。浅纸色和固定深色墨水搭配，保证可读。
- **墨水**：所有便签统一固定深色 **`#2b2b2b`**，不按便签变。
- **预览字号**（`fs`）：**0.1 – 2.0 m**，默认 **0.2 m**；卡片上 `A−` / `A+` 的一档是当前字号的 ~25 %
  （≥ 0.05 m）。字号是「米」，便签越大就要调得越大。
- 便签落在该位置的地表高度上，加一点偏移（**2 cm**），避免和地面 z-fighting。纸是圆角的，圆角
  **被裁掉**（材质 `transparent` + `alphaTest`），所以露出来的是地面，不是黑角。
- 预览贴图按 **384 像素 / 米** 画（默认 2 × 1.5 m 的便签 = 768 × 576），文字落在整像素上。
  **像素预算以旧的最大便签（6 × 6 m = 2304 × 2304）封顶**：更大的便签是降低密度，而不是多分配像素
  （总数不超过 2304 × 2304，单边不超过 **4096 px**——再大有 GPU 会直接失败）。

## 5. 在地面上查看

- 文字**永远绘制**在便签上——任何缩放级别都一样（取舍见 §10）。
- 内容超过便签时，**在基础宽度内换行、超出基础尺寸的部分裁掉**；所见即所得编辑器里能看到全部。

## 6. 编辑

1. **单击选中**便签；不会误进编辑，也不和相机 / 选择拖拽打架——四角的句柄（§4）和卡片（§7）就是
   这时候出现的。
2. **双击直接在便签上写。** 文字是**在世界里、写在纸上的**：一个 `contenteditable` 用仿射
   `transform: matrix(…)` 贴在便签上（相机是正交的，所以这是精确的——实测 DOM 的矩形和便签投影
   差不到 1 px），同时把那张贴图切成**只剩纸面**。所以你打的字就是便签上的真文字、清晰；`Esc`、
   `⌘/Ctrl+Enter` 或点到别处，就把它画回纸面贴图上。
3. 卡片里的 **编辑**打开**完整的所见即所得编辑器**（另一条路）。

- **编辑器**：**Quill v2**（新增依赖；`app/app.css` 里 `import 'quill/dist/quill.snow.css'`，由 `quillFor` 懒加载）。它可替换，因为存盘格式是我们自己的，不是 Quill 的。
- **自动保存**：打字停顿 600 ms 自动写入便签数据，底部显示实时反馈（**保存中…** → **已保存**）。
  任何关闭路径（`Esc`、点击暗色背景蒙层、点击「完成」）均立即写入，无需手动按保存也不会丢失内容。
- **存储内容**：一个小的**清洗过的 HTML 子集**，白名单
  `p · br · b · strong · i · em · u · h1 · h2 · h3 · ul · ol · li · a[href]`。其余一律在读取时剥掉
  （这个 fork 特意去掉了 `innerHTML`）。地面预览用同一子集渲染进便签的 canvas 贴图。

## 7. 便签卡片

一张卡片，挂在选中的便签上，里面**和其他元素一样都是普通按钮**：

- **背景色**——换到下一种纸色，按钮上的小圆点显示当前纸色。
- **`A−` / `A+`**——预览字号（档位跟着当前字号放大）。
- **旋转**——90°。
- **缩小 / 放大**——基础尺寸的粗调，档位跟着当前尺寸放大（≥ 0.5 m；细调用四角的句柄）。
- **编辑**——打开所见即所得编辑器。
- **删除**——删除前会确认（§8）。

## 8. 撤销

- **便签内容不可撤销。** 和摆设、宫殿不同（它们会压入 `editor.ts` 的撤销快照），便签的文字编辑
  在撤销历史之外。
- **删除前会确认**——这是针对「删除不可撤销」的唯一一道保险。

## 10. 取舍

- **文字永远绘制**（而非按距离 LOD）：拉到群岛 / 星球级别时，文字会小到不足一个像素、基本不可读。
  接受；彩色方块仍然标出便签位置。
- **便签内容不可撤销**：文字编辑和删除都在撤销栈之外。只靠删除确认来兜底。
- **特大的便签贴图密度更低。** 像素预算固定（§4），所以 40 m 的便签按 ~57 像素 / 米 画：纸面和字比小
  便签糊一些。在便签上原地写字不受影响——那层是真正的 DOM 文字，按屏幕分辨率光栅化。因此把便签放大
  不会多占显存。
- **不处理碰撞**：便签是平的、不阻挡，所以能放在地面的任何地方，包括宫殿和摆设附近或上面。

## 11. 验收标准

- 能用便签工具点地面放下一张便签，吸附（5 cm、吸附开关、Alt）和旋转（15°、`R` 90°）与摆设完全
  一致；重载后还在（版本 5，旧存档仍能读）。
- 按基础尺寸平铺在地面上，文字永远绘制、可读。
- 内容超过基础尺寸时在地面上换行并裁掉；所见即所得编辑器里能看到全部。
- 单击选中并弹出菜单；双击原地编辑；编辑打开 Quill，支持加粗 / 斜体 / 下划线、标题、列表、链接，
  存成清洗过的子集。
- 菜单能改背景色、预览字号、基础尺寸，打开编辑器，并在确认后删除。尺寸实际上不限：1.0 – 40.0 m，
  而且放大到 40 m 也还是 ≤ 2304 × 2304 px 的贴图、单边 ≤ 4096 px。
- 墨水固定 `#2b2b2b`；界面文字走 `t()`、英文落在 `src/i18n/en/`；
  `pnpm typecheck && pnpm test` 保持通过。
